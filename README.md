# 그림으로 읽는 성경

**VCS 해설 한국어 번역** — 킹스 칼리지 런던의 [Visual Commentary on Scripture](https://thevcs.org/)(VCS)가 엮은 해설 전시를 VCS의 허락을 받아 한국어로 옮기는 사이트입니다.

사이트 주소: https://hunj08423-debug.github.io/vcs-ko/

## 권리

- 해설 원문과 그 한국어 번역의 저작권은 필자와 VCS에 있습니다. 다른 곳에 옮겨 실으려면 VCS의 허락이 필요합니다.
- 그림은 위키미디어 공용의 파일을 쓰며, 각 전시 페이지 아래 '출처와 저작권'에 파일과 라이선스를 적습니다.
- ‘먼저 보기’, ‘그림에서 볼 것’, 낱말 풀이, 구절 지도, 질문은 이 사이트가 덧붙인 글입니다.

## 파일

| 자리 | 내용 |
| --- | --- |
| `index.html` | 첫 화면 |
| `annunciation.html` | 전시 페이지 (수태고지) |
| `make.html` | 페이지 만들기 도구 — 원문·번역 대조본(.docx)을 넣어 미리 보기, 검토용 링크, PDF, 번역 파일을 만든다 |
| `spots.html` | 그림 위 번호 찍기 도구 — 문장 번호마다 핀과 네모, 이름, '그림에서 볼 것'을 적어 내보낸다 |
| `_template.html`, `data/_template.js` | 새 전시 페이지와 자료의 틀 |
| `HOWTO.md` | 새 전시 만드는 순서 |
| `site.js` | 사이트 이름과 주소 |
| `exhibit.js`, `exhibit.css` | 전시 페이지 공통 코드와 모양 |
| `data/` | 전시마다 사이트 쪽 자료 (그림 정보, 그림 위 번호, 구절 지도, 낱말 풀이). 번역문은 넣지 않는다 |
| `text/` | 번역 파일. `*.js`는 VCS 승인 뒤 공개용, `*.review.js`는 검토용 잠금 파일 |
| `img/` | 그림 |

## 순서

새 전시를 만드는 자세한 순서는 [HOWTO.md](HOWTO.md)에 있습니다. 줄이면 이렇습니다.

1. `make.html`에 대조본을 넣고 미리 본다.
2. ‘검토용 링크 만들기’로 잠금 파일과 링크를 만들고, 잠금 파일을 `text/`에 올린 뒤 링크와 PDF를 VCS에 보낸다. 잠금 파일은 그 링크의 열쇠로만 열린다.
3. VCS가 승인하면 ‘공개용 번역 파일’을 `text/`에 올리고, 검색 차단(noindex)을 푼다.
