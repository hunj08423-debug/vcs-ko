전시 페이지 만들기

대조본 파일을 넣으면 페이지를 미리 보고, VCS에 보낼 검토용 링크와 PDF, 공개용 번역 파일을 만들 수 있어요.

1. 대조본 파일 넣기

원문·번역 대조본(.docx)을 끌어다 놓거나 골라 주세요. 파일은 이 브라우저 안에서만 읽고, 어디에도 보내지 않아요.

    2. 옮긴이 주 고르기

    해설 속 ‘(역주: …)’를 따로 뽑았어요. 사이트에 실을 것만 고르고, 필요하면 고쳐 주세요. 고치면 아래 미리보기에 바로 반영돼요.

    3. VCS에 보낼 검토용 링크 만들기

    아래 미리보기를 끝까지 읽어 본 뒤 단추를 누르세요. 번역을 잠근 파일과, 그 잠금을 여는 링크가 한 쌍으로 생겨요. 링크가 없는 사람에게는 빈 틀만 보이고, 검토용 링크에서는 문장마다 영어 원문을 켜고 끌 수 있어요.

    새 창에서 열어 보기 ↗
    1. 방금 내려받은 annunciation.review.js 파일을 GitHub의 vcs-ko 저장소 text 폴더에 올리세요. ‘Add file → Upload files’로 끌어다 놓고 ‘Commit changes’를 누르면, 같은 이름의 빈 파일이 바뀌어요.
    2. 1~2분 뒤 ‘새 창에서 열어 보기’로 번역이 열리는지 확인하세요.
    3. 확인되면 링크를 복사해서 Joost님께 보내세요.

    이 브라우저에서는 검토용 링크가 늘 같아요. 내용을 고쳐 다시 만들면 새로 받은 파일만 다시 올리면 되고, 링크는 그대로 써도 됩니다.

    다른 컴퓨터에서 만든 링크를 계속 쓰려면

    이미 보낸 검토용 링크를 아래 칸에 붙여 넣은 뒤 ‘검토용 링크 만들기’를 누르세요. 그 링크의 열쇠로 잠가서, 같은 링크로 열려요.

    4. PDF와 공개용 번역 파일

    PDF는 검토용 링크와 함께 보내면 좋아요. 공개용 번역 파일은 VCS가 승인한 뒤에 씁니다.

    공개용 번역 파일은 VCS가 승인한 뒤에 올려 주세요. 올리는 순간 누구나 볼 수 있게 됩니다. 이 파일에는 영어 원문이 들어가지 않아요.

    1. PDF로 저장: 인쇄 창이 뜨면 ‘대상’을 ‘PDF로 저장’으로 고르고 저장합니다. 영어 원문을 켜 둔 채 저장하면 PDF에도 함께 들어가요.
    2. 승인을 받으면 ‘공개용 번역 파일 내려받기’를 누르고, 생긴 annunciation.js 파일을 같은 방법으로 text 폴더에 올립니다.
    3. 그다음 Claude에게 “공개해 줘”라고 하면 검색 차단을 풀고 첫 화면에 연결해 드려요.
    4. 올린 뒤 페이지가 바로 안 바뀌면 1~2분 기다린 다음, Ctrl+Shift+R(맥은 Cmd+Shift+R)로 새로 고침해 보세요. 브라우저가 예전 파일을 잠시 기억하고 있을 수 있어요.
